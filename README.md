## 🌟 About The Project

**OpenSource Screen Recorder** is a lightweight screen recording tool built with **Python**.

Capture your entire screen or a selected region with a simple interface — without unnecessary bloat or complicated configuration.

The project is designed to be **simple, customizable, and open-source**.

---

## ✨ Features

* 📹 **Full Screen Recording**
* 🎯 **Selected Region Recording**
* 🎙️ **Microphone Input**
* 🔊 **System Audio Support**
* 🎞️ **MP4 / AVI Export**
* 🧊 **Minimal GUI**
* ⚡ **Fast & Lightweight**
* 🧩 **Open-Source & Customizable**
* 🖥️ **Windows Support**
* 🐧 **Linux Support**

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/luciferofx/opensource-screen-recorder.git
```

```bash
cd opensource-screen-recorder
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Application

```bash
python main.py
```

> Replace `main.py` with the actual entry-point filename if your project uses a different file.

## 🐛 Troubleshooting

### PyAudio Installation Error

If PyAudio fails to install, make sure the required system audio dependencies are installed for your operating system.

### Tkinter Not Found

Verify that Tkinter is available in your Python installation.

### Recording Doesn't Start

Check:

```text
✓ Python version
✓ Required dependencies
✓ Screen permissions
✓ Microphone permissions
✓ Output directory permissions
```
